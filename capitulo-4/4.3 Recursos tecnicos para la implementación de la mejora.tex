\subsection{Recursos técnicos para la implementación de la mejora}

Para el desarrollo, codificación, contenedorización y pruebas del sistema web de gestión de nóminas y recursos humanos, 
se utilizaron estaciones de trabajo portátiles asignadas a cada desarrollador, 
así como herramientas de software de código abierto y servicios de gestión en la nube.

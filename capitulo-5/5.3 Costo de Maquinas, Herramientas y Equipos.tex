\subsection{Costo de Máquinas, Herramientas y Equipos}
\subsubsection{El Costo de Depreciación de herramientas}

Para el cálculo del desgaste físico y obsolescencia de los equipos de cómputo asignados a los desarrolladores durante la ejecución del proyecto, se aplica el método de \textbf{depreciación lineal}. Bajo este procedimiento contable, el activo pierde valor de manera constante a lo largo de su vida útil estimada, deduciendo previamente su valor residual.

Las ecuaciones matemáticas que rigen este cálculo son las siguientes:

\begin{equation}
    \text{Valor residual} = \frac{\text{Valor inicial}}{\text{Vida útil en años}}
\end{equation}

\begin{equation}
    \text{Depreciación anual} = \frac{\text{Valor inicial} - \text{Valor residual}}{\text{Vida útil en años}}
\end{equation}

A manera de aplicación demostrativa para la estación de trabajo principal del proyecto (Laptop HP Omen 16), cuyo valor de adquisición es de S/ 2,850.00 y posee una vida útil de 6 años:

\begin{equation*}
    \text{Valor residual} = \frac{\text{S/ } 2,850.00}{6} = \text{S/ } 475.00
\end{equation*}

\begin{equation*}
    \text{Depreciación anual} = \frac{\text{S/ } 2,850.00 - \text{S/ } 475.00}{6} = \frac{\text{S/ } 2,375.00}{6} = \text{S/ } 395.83
\end{equation*}

Según el método de depreciación lineal, el importe depreciable de esta estación asciende a S/ 2,375.00, 
registrando una pérdida de valor anual constante de S/ 395.83 hasta alcanzar su valor residual contable de S/ 475.00 al sexto año. 
La memoria de cálculo contable proyectada año tras año para esta estación de trabajo se detalla en el \textbf{Anexo~1}.

Generalizando este procedimiento de cálculo para las seis estaciones de trabajo empleadas por el equipo de desarrollo, se determina el costo de adquisición, 
el valor residual y la alícuota de depreciación anualizada de cada equipo en la Tabla~\ref{tab:depreciacion_equipos}.
